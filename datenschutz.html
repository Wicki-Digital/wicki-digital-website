2. Website und technische Bereitstellung

Der Hostingdienst wird von GitHub bereitgestellt; dessen Datenschutzhinweise nennen GitHub, Inc. (USA) und GitHub B.V. (Niederlande). Zur technischen Auslieferung können von GitHub eingesetzte Infrastruktur- und Netzwerkdienstleister hinzukommen. WICKI DIGITAL setzt diese technischen Vorgänge nicht für ein eigenes Besuchsprofil oder personalisierte Werbung ein.

Bei der geprüften Auslieferung ist ausserdem Fastly (USA) als von GitHub eingesetzter Dienst zur schnellen Bereitstellung von Inhalten erkennbar. Dabei werden technische Anfragedaten für die Übertragung und Zwischenspeicherung der Website bearbeitet; es handelt sich nicht um einen von WICKI DIGITAL eingebundenen Werbetracker.
